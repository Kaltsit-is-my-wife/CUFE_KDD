MARTI: A Framework for Multi-Agent LLM Systems Reinforced Training and Inference（ICLR 2026 主会）	TsinghuaC3I/MARTI: [ICLR 2026] A Framework for LLM-based Multi-Agent Reinforced Training and Inference	清华 C3I 实验室推出的推理 - 训练一体化多智能体框架，核心是将多智能体协作推理与分布式强化学习深度融合。采用中心化Multi-Agent World交互环境统一管控智能体交互、生成协作轨迹与全局信用分配；支持动态自定义工作流与异步多轮推理，内置规则可验证奖励 + LLM 生成式奖励的双轨奖励机制，底层对接 OpenRLHF 实现分布式策略训练，可面向复杂长周期任务完成端到端的多智能体策略优化
Multi-Agent Collaboration via Evolving Orchestration（NeurIPS 2025 主会）	https://github.com/OpenBMB/ChatDev/tree/puppeteer	核心架构为「中心化编排器（Puppeteer）+ 执行智能体池（Puppets）」。编排器通过强化学习训练，根据任务实时执行状态动态调度、激活 / 停用不同智能体，自适应重构协作拓扑结构，而非传统静态固定的角色分工
OxyGent: Making Multi-Agent Systems Modular, Observable, and Evolvable via Oxy Abstraction（ACL 2026）	https://github.com/jd-opensource/OxyGent	所有协作要素（智能体、工具、约束、目标）统一抽象为可插拔的 Oxy 原子，运行时自动生成可视化执行图，全链路状态可追踪；内置 OxyBank 演化引擎，支持运行时动态增删模块、调整协作逻辑，无需重启系统。
SYMPHONY: Synergistic Multi-agent Planning with Heterogeneous Language Model Assembly(NeurIPS 2025)	https://github.com/ZHUWEI-hub/SYMPHONY	异构大模型驱动的协同多智能体规划框架。核心是「异构智能体池 + 多智能体蒙特卡洛树搜索（MCTS）」，通过集成不同能力、不同规模的 LLM 智能体，利用推理多样性互补短板；通过分布式 MCTS 规划算法协同探索决策空间，在复杂推理、规划任务上显著优于单模型与同构多智能体系统。
AgentNet: Decentralized Evolutionary Coordination for LLM-Based Multi-Agent Systems(NeurIPS 2025)	zoe-yyx/AgentNet: [NIPS2025] A decentralized, RAG-enhanced multi-agent framework for LLMs with dynamic task routing and agent evolution.	去中心化的演化式多智能体协调框架，无中心化编排节点。核心采用「动态任务路由 + RAG 增强的智能体演化机制」，智能体之间通过消息网络自主交互、自主分配任务，每个智能体可通过 RAG 动态更新自身知识与能力边界，随任务推进自主演化角色与分工。内置演化选择机制，低效智能体会被网络边缘化
AgentVerse: Facilitating Multi-Agent Collaboration and Exploring Emergent Behaviors in Agents	https://github.com/OpenBMB/AgentVerse	OpenBMB 推出的通用多智能体协作仿真框架，主打低代码配置与涌现行为探索。支持快速自定义智能体角色、能力、交互规则与协作模式，内置协商式、层级式、去中心化式等多种经典协作范式可一键切换；提供完整的环境仿真与行为观测工具
MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework(2024 ICLR 多角色经典框架)	FoundationAgents/MetaGPT: 🌟 The Multi-Agent Framework: First AI Software Company, Towards Natural Language Programming	经典的元编程式多智能体协作框架，模拟软件公司的角色分工与工作流，将产品经理、架构师、工程师、测试等角色封装为独立智能体，通过标准化的 SOP 流程与结构化消息传递完成复杂软件开发任务。核心是用角色职责固化协作边界，用结构化输出保证信息传递一致性，是多角色流水线协作范式的经典
ChatDev: Communicative Agents for Software Development（ACL2024）	OpenBMB/ChatDev: ChatDev 2.0: Dev All through LLM-powered Multi-Agent Collaboration	面向软件开发场景的通信式多智能体框架，也是 Puppeteer 等多项顶会工作的基础底座。核心是通过自然语言驱动多智能体完成需求分析、代码编写、调试、测试等软件开发全流程，内置成熟的多智能体交互、记忆、工具调用基础组件；支持高度自定义角色、工作流与工具调用，可二次开发扩展各类协作场景
