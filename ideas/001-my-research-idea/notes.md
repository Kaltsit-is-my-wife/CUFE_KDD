### [调研 #1] 数据挖掘领域现状综述（2026-09）

> 全文见 [`survey-data-mining-2026.md`](survey-data-mining-2026.md)

- 研究问题：数据挖掘领域十个主要方向在 2023–2026 年的现状、共识与争议分别是什么
- 覆盖方向与规模：10 个方向，约 90 篇文献，时间重心 2023–2026
- 核心方法：并行文献检索 + 逐条来源核验 + 横向争议比对（非 PRISMA 系统性综述）
- 主要结论：
  1. **祛魅期**——十个方向在 2024–2026 几乎同步走出「新范式宣称碾压 → 基准被证伪 → 结论条件化」的同一条曲线（时序 TSFM、异常检测深度架构、因果发现、生成式推荐 SID、多模态组合推理、联邦学习收益，无一例外）
  2. **LLM 是通用接口而非通用解法**——在语言-语义主导任务上碾压，在结构化/数值主导任务上（表格、时序、异常检测）至今未取代专用方法
  3. **评测危机是全领域元问题**——数据泄漏、基准缺陷、离线指标与真实效用脱节，在至少六个方向被独立指出
- 原文/本综述的贡献：把十个方向的争议横向对齐，识别出共同的失效机制（合成/公开基准与真实场景的系统性偏差）
- **我的判断**——哪些结论可信、哪些存疑：
  - 可信：「祛魅期」这条主线的证据密度很高，且由多个方向的**独立**工作支撑，不是单一团队的观点
  - 存疑：第 12 节的 4 个切入点是我的推断，**没有实验证据**，属于方向假设而非结论
  - 局限：非系统性综述，检索以 WebSearch 为主，可能有遗漏；KDD 录用率等数据来自第三方
- 对本团队方向的启发：**评测与基准方向可能是差异化优势**——中财背景在金融/经济数据上，公开数据集的泄漏与时间切分问题可能比 CV/NLP 更严重，而这条线恰好是领域当前的痛点
- 与本团队现有工作的差异/风险：目前团队尚无既有工作，不存在直接冲突；风险是切入点过宽，需要收窄到可证伪的具体假设
- 可复现的部分：全部引用的链接可直接验证；检索方法记录在综述第 13 节
- 是否值得跟进（**是**），下一步动作：从第 12 节挑 1–2 个切入点，写成带【核心假设】的正式 idea 编号

### [调研 #2] 候选方向新颖性核查（两轮）

> 汇总报告见 [`topic-landscape-2026.md`](topic-landscape-2026.md)

- 研究问题：从综述的候选切入点中，筛出「首篇位置还空着 + 门槛可控」的方向
- 核心方法：对每个候选做独立新颖性核查——检索直接占位者 → 判定论文密度 → 定位最接近工作 → 判断缺口是真空白还是检索不到
- 核查对象：多模态信号有用性诊断、金融数据泄漏审计、AI 污染对下游挖掘、Agent 失败归因/HITL、基础模型路由、MCP 工具生态
- 主要结果：**6 个候选里 4 个首篇已被占**
  - ❌ 多模态诊断 → 被 arXiv:2508.07399（ECIR 2026）占，已形式化为 "Modality Knockout"
  - ❌ Agent 失败归因 → Who&When (ICML'25)，16 个月 55 篇，已有 IEEE TSE 综述
  - ❌ MCP 检索/安全 → 25+ 篇 / 20+ 篇，各 3 篇与 2 篇综述
  - ❌ 时序 FM 路由 → 2026 年 5+ 篇集中攻占
  - 🟢 金融数据泄漏审计 → KDD 层面确认空白（缝在审计对象，不在方法）
  - 🟢 AI 污染对下游挖掘 → 上游下游皆红海，中间层真空
- **我的判断**——哪些结论可信、哪些存疑：
  - 可信：「太新类蓝海保质期只有 6–12 个月」这条，由 4 个独立核查交叉验证
  - 可信：金融泄漏审计的空白判断——核查者专门去 KDD 2026 accepted / PhD Consortium / 金融专题分别检索，确认是真空而非关键词问题
  - 存疑：MCP 工具冲突仲裁「0 篇」的结论，可能受检索词限制
- 对本团队方向的启发：**中财的优势是「场景门槛」型蓝海**——数据获取门槛（PIT 数据）挡掉大部分竞争者，而这类蓝海保质期以年计
- 风险：AI 污染方向现象漂移快；金融方向可能被批评「不该投 KDD」
- 可复现的部分：全部核查依据记录在报告第 2、4 节
- 是否值得跟进（**是**），下一步动作：确认 PIT 数据获取路径（WRDS 授权？A 股聚源数据？）

### [调研 #3] KDD 2026 AI 方向调研与 idea 候选

> 全文见 [`kdd-ai-survey-2026.md`](kdd-ai-survey-2026.md)

- 研究问题：KDD 的 AI 方向现状如何，其中哪些格子还能长出可做、可证伪的 idea
- 覆盖范围：KDD 2026 全量 **1415 篇**录用论文（官方页内嵌 JSON 实抓）；四个 AI 子方向深挖——Agent 记忆 / 检索与 RAG / 生成式推荐 / 图×LLM
- 核心方法：官方论文列表实抓解析 + 对每个子方向做「盘点 → 方法脉络 → 瓶颈与已证伪点 → idea 候选」四步
- 主要结论：
  1. **AI 是 KDD 主轨的主力**——Research 787 篇中标题含 AI 关键词约 300 篇（≈38%），做 AI 方向投 KDD 完全成立
  2. **四个 AI 子方向同步「祛魅」**——宣称的增益追查下去都来自混杂因素或评测缺陷（长上下文 ≠ 长记忆 / GraphRAG 多数任务不如 vanilla RAG / 扩散推荐 75% 不可复现 / 图提示存在负迁移）
  3. **D&B track 是被低估的入口**——录取率 **27%**，高出 Research（18.5%）近 9 个百分点，且 CFP 无泄漏/复现硬门槛
  4. **最易被接受的贡献形态**：「指出旧结论的混杂来源 → 给出可判定条件 → 在新条件下验证」
- **我的判断**——哪些结论可信、哪些存疑：
  - 可信：四类「祛魅」均由**独立**工作支撑，且多篇已正式发表于顶会/期刊（NoLiMa ICML'25、LongMemEval ICLR'25、Illusion of Progress TORS'26、Don't Get Ahead of Yourself RecSys'25）
  - 可信：序列推荐时序泄漏的数字（nDCG@10 跌 21.7–73.4%、7/8 组最优模型换位）有**正式论文 + 公开代码**双重支撑
  - 存疑：四个子方向的 idea 均为**推断**，无实验证据，属方向假设
  - 局限：KDD 论文正文未打开（ACM DL 403），核验止于官方页 JSON；开源性未逐条核验
- 对本团队方向的启发：**「改进 A」路线成立的前提是「A 的弱点真实」**——首选走廊 A（SID 放大时序泄漏），因为它同时满足「弱点已被正式确立」+「具体机制无人测过」+「单卡可复现」

### [调研 #4] 精读本组 ICDM'25 论文 DriftHunter + Web Agent × 多模态调研

> 全文见 [`drifthunter-and-webagent-survey-2026.md`](drifthunter-and-webagent-survey-2026.md)

- 精读对象：Yue Wang et al., *Detecting Intent Drift in Continuous Conversation via Temporal Transition Accumulation*, **ICDM 2025**, pp. 773–782，**中央财经大学信息学院**（本组论文），代码 `github.com/FDHTJ/DriftHunter`
- 研究问题：如何在单会话长对话中检测用户意图的任意漂移
- 数据集与规模：ATIS（5,866 句）、SIM（23,357 句）、MultiWOZ（128,296 句）；另人工合成「长连续会话」（随机打乱对话后拼接）
- 核心方法：encoder–decoder 多任务架构中夹入可微的 DriftHunter 模块，四组件 = 局部表示学习 + **intent–slot 转移累积**（联合标签空间转移矩阵 $M_t=\lambda M_{t-1}+(1-\lambda)M'_t$）+ 全局转移注入 + token 级增强
- 主要指标与结果：接入后平均 F1 提升 **drift +6.4% / intent +4.6% / slot +7.3%**；去掉 drift 子任务会使 ATIS 的 slot filling P 从 83.7 掉到 62.5
- 原文声称的贡献：①首次形式化 intent drift detection 任务；②首个可微的跨轮 intent–slot 时序累积方法；③在三个下游任务上同时验证
- **我的判断**——哪些结论可信、哪些存疑，理由：
  - ✅ **可信**：「可微转移累积」相对 DHLG 的离线统计图确实更适合长会话；「去 drift → slot filling 崩 21 点」这条消融干净有力
  - ❌ **硬伤**：(1) 合成的长会话把 drift 退化成「相邻两句是否同一话题」——这正是 SIM 上能刷到 99.9 的原因，与 intro 里「SFT 一词两义」的真实难点脱节；(2) **无关键基线**，没有「只用相邻两句」的强对照，因此**无法证明跨轮累积是必要的**；(3) 输入含 $u_{k+1}$，是后验判定而非在线预测，与宣称的 online switching 名不副实；(4) DHLG 在 ATIS 的 slot filling 29.6 属异常值，污染对照表；(5) 式 11 的固定 λ 递归等价简化 RNN，长序列病态性未测
  - ⚠️ **存疑**：「DeepSeek-R1-8B 不会判漂移」（P=45.7/R=96.5）更可能是 prompt 未校准所致，不能直接解读为 LLM 能力问题
- **一句话评价**：**价值在于把 intent–slot 跨轮转移做成可微、可端到端训练的累积模块，第一次让意图漂移可被在线检测；但评测把漂移退化成「相邻两句话题是否相同」的二分类，又缺少「不累积也能打平」的强基线，核心机制的必要性从未被真正证明。**
- 对本团队方向的启发：**这既是本组已有武器，也是一个现成的改进空间**——缺陷 (1)(2) 就是最自然的切入点，且「会推翻作者自己结论」的改进方向符合调研 #3 总结的选型逻辑
- 与本团队现有工作的差异/风险：无冲突（本组论文）；风险是若做方向 A 并证实累积无必要，需注意对内沟通方式
- 可复现的部分：论文 V-B 的合成长会话构造步骤可完整复现（这是方向 A/F 的前提）；代码已开源
- 是否值得跟进（**是**），下一步动作：**先跑方向 A**（相邻两句强基线，成本极低、信息量极高），再读穿 `2505.02709`（goal drift）与 `2607.20734`（evolving user intent，未核实）

#### [调研 #4 附] Web Agent × 多模态线的主要发现

- 三主线：多模态 Web Agent（WebArena / VisualWebArena / SeeAct / AgentOccam / UGround）、GUI Agent（OSWorld / CogAgent / UI-TARS / AguVis）、**与意图漂移的交叉线**（NoLiMa / LongMemEval / goal drift / PIRA-Bench）
- **核心争议**：VisualWebArena 官方消融显示视觉仅带来 +8 点增益（7.25% → 16.37%），且 AgentOccam 证明**纯文本剪枝就能反超**多模态方案 → **视觉是必要非充分，grounding 才是真瓶颈**
- **评测危机**：WebArena-Verified 审计 812 任务发现 299 个评测错误并弃用 LLM-as-judge；有工作称 10 个 agent 基准中 8 个有缺陷 → **与本组「评测危机」主线完全同构**
- **缝隙判断**：「多模态 agent × 意图漂移检测」是**缝隙而非空白**，PIRA-Bench 的状态转移语义与 DriftHunter 高度同构，窗口 ≤6 个月 → **立项前必须打开 PIRA-Bench / ScenDroid 原文核实**
- ⚠️ **可信度声明**：2026 年条目（`26xx.xxxxx`）多为摘要级，**未逐篇打开原文**，引用前须在 arXiv 核对
