## 2. 一句话摘要

系统性地收集、精读和整理与本团队研究方向相关的文献与开源方案，沉淀可复用的调研结论，并从中提炼出可证伪、可实验的 idea 候选。

## 3. 本目录放什么 / 不放什么

**放：**

- 调研文章的阅读笔记、方法对比、关键结论（写在 `notes.md`）
- 由调研衍生的 idea 想法，含核心假设、可观测指标、数据集设想
- 想法落地为实验时的实验设计（写在 `experiment.md`）
- 小规模的数据观察记录

**不放：**

- 原始数据、模型权重、大日志、凭据（仓库硬性禁止）
- 正式实验的可运行代码和结果（应迁到 `experiments/NNN-short-name/`）
- 尚未整理、不打算复现的临时草稿（那属于 `sandbox/`）
