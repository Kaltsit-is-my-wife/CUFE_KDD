## 调研文章笔记

### [调研 #1] 立项前新颖性核查：agent 间漂移是否已被占位

> 核查日期 **2026-09-29**，方法：多路 WebSearch/WebFetch + 逐条来源核验

- **研究问题**：把 DriftHunter 的"跨轮转移累积"迁移到多 agent 交互，这个位置是否还空着？
- **核查口径**：**已核实**＝打开了 arXiv/会议官方页读到题名、作者、日期、摘要；**未核实**＝仅搜索结果摘要
- **主要发现**：

| 工作 | 编号/出处 | 核实状态 | 与本 idea 的距离 |
|---|---|---|---|
| *Inherited Goal Drift* | `2603.03258`, ICLR 2026 Lifelong Agents Workshop | **已核实** | **最直接竞争**：确认研究 **agent 之间**的漂移传染（条件化于弱 agent 轨迹后"继承"漂移）；但非在线检测、无转移矩阵 |
| MAST / *Why Do Multi-Agent LLM Systems Fail?* | `2503.13657`, NeurIPS 2025 | 未核实（见官方 poster 页） | **问题层已被命名**："Task derailment"、"Disobey role specification" |
| *Spectral Dynamics of Semantic Drift* | `2607.22758` | 未核实（**单作者预印本**） | **方法层已被逼近**：用 `M=(1−γ)I+γW` 在 agent 通信图上做谱分析，与 `M_t=λM_{t-1}+(1−λ)M'_t` 结构相近 |
| *Agent Drift* | `2601.04170` | 未核实（**单作者预印本**） | 定义 inter-agent coherence 退化，ASI 12 维复合指标（事后聚合） |
| *Hallucination as Context Drift* | `2606.21666` | 未核实（**单作者预印本**） | 成对余弦散度 + 同步协议，无转移矩阵 |
| *Evaluating Goal Drift in LM Agents* | `2505.02709` | **已核实** | **不涉及 agent 之间**；arXiv 页**无 venue**，此前流传的 "AIES'25" **未能证实** |
| MasDrift | `2608.07556` | 未核实 | 授权/约束漂移；**71.9% 约束丢失发生在第 1 次 handoff** |
| CAMEL | `2303.17760`, NeurIPS 2023 | 未核实（原文未打开） | 记录 role flipping / instruction repetition / infinite loops，**无量化漂移率** |

- **最终判断**：
  - **定性：缝隙 > 空白，缝隙正在收窄。** 置信度**中高**。
  - **已被占位**：「多 agent 漂移检测」作为**问题**（MAST 命名、ASI/CDS 量化、谱分析形式化）
  - **仍空着**：「**语义意图层的在线可微检测**」——现有工作要么是 post-hoc 行为指标，要么是拓扑/谱分析，**无人做逐轮语义状态的可微累积 + 单步跳变信号**
  - **转移矩阵本身不再是卖点**（Spectral Dynamics 已用类似结构）→ 卖点必须落在**语义单位定义**与**单步跳变检测**
- **致命障碍（已识别）**：ATIS/MultiWOZ 有成熟 intent/slot 本体，**agent–agent 交互没有**。原方法**输入层无法直接迁移**。缓解方向：把 slot 重定义为 role / goal-atom / tool-action / commitment / constraint——**但这已改写 DriftHunter 的假设**，所以必须先做 P1 探针验证本体可标注性。
- **可信度声明**：2026 年条目中多篇为**单作者、无 venue 的 arXiv 预印本**，投稿引用前**必须逐一打开原文核实**
- **是否值得跟进（是，有条件）** → 条件 = P1 探针（标注一致性 κ ≥ 0.6）通过

## 术语与约定

| 术语 | 定义 | 备注 |
|---|---|---|
| 语义原子 | agent 交互轮的可标注最小单位（role / goal-atom / tool-action / commitment / constraint） | 本 idea 的核心构造，替代 DriftHunter 的 intent/slot |
| 漂移（本 idea 语境） | agent 轮次序列上 `goal-atom` 的非预期偏移，**排除任务分配或显式指令触发的合法切换** | 边界必须在标注协议中写死 |
| 单步定位 | 指出漂移发生在**哪一轮**，而非仅判断"有/无漂移" | 与 post-hoc 行为指标的核心差异 |
| 置换零分布 | 轨迹内打乱轮次顺序后重算漂移率形成的分布 | 用于 P2 显著性检验 |
