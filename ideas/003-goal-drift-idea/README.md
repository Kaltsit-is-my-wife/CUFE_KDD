## 一句话摘要

在不调用大模型 API 的受控合成环境中，研究在线目标漂移检测、漂移感知记忆更新及其对确定性下游任务的影响。

## 问题与背景

- 长期运行的 Agent 可能在多轮会话中改变目标，旧目标记忆会干扰后续决策。
- 仅检测漂移不足以保证任务收益；检测时机、误报以及记忆更新的可逆性都可能改变最终效果。
- 本 PoC 用因果、确定性的规则系统隔离这些机制，并保留失败案例和负面结论。

## 【核心假设】

如果在线检测到目标变化时采用可逆的早期记忆降权，那么相对于确认后才更新的策略，任务成功率和过时记忆识别质量将提升，同时背景记忆保留率不低于 0.98、稳定场景成功率下降不超过 0.02；预注册的主要增益门槛为任务成功率至少提升 0.05。

## 研究问题

1. 更早的检测是否稳定改善下游任务？
2. 可逆更新是否能处理临时变化并保护背景记忆？
3. 记忆识别指标的改善能否转化为达到门槛的任务收益？

## 数据集与实验方案

实验使用代码生成的受控合成轨迹，不含个人信息或外部受限数据。Phase 3 使用种子 `20270417`，开发/测试轨迹分别为 112/224。方法包括 Method C/D/E confirmation，以及原始/改进更新、Early Reversible、No Update 和仅作诊断上界的 Oracle Timing。统计使用轨迹级 bootstrap、配对随机化检验和 Holm 校正。

## 结论与限制

- Early Reversible 相对 D 的任务成功率提升为 `0.020`，95% CI `[0.009, 0.032]`，未达到预注册的 `0.05` 门槛。
- Early Reversible 的过时记忆 F1 为 `0.865`，高于 D 的 `0.824`，但指标改善未充分转化为任务收益。
- 背景保留率为 `1.000`，稳定场景相对 D 无下降。
- 最终决策：`STOP_OR_REVISE_CURRENT_IMPLEMENTATION`。
- 有限人工词典、合成分布和确定性效用模型限制外部有效性，不能外推为真实 LLM Agent 效果。
