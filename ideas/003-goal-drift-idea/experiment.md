# [003] 实验设计

## 实验目标

验证早期可逆记忆更新能否在保护背景记忆和稳定场景表现的同时，相对确认后更新策略显著提高任务成功率。

## 变量与对照

| 类型 | 内容 |
|---|---|
| 自变量 | 检测方法与记忆更新策略 |
| 因变量 | 检测 F1、定位误差、任务成功率、过时记忆 F1、背景保留率 |
| 控制变量 | 合成数据生成过程、随机种子、冻结参数、因果输入前缀 |
| 对照组 | No Update、C/D 原始与改进记忆策略 |
| 诊断上界 | Oracle Timing（不可部署，不参加公平排名） |

## 数据与切分

- 受控合成数据；Phase 3 开发/测试轨迹为 112/224。
- 开发参数固定后才连接测试标签。
- 检测器只读取截至当前会话的前缀；标签只用于评估。

## 指标与验收标准

| 指标 | 方向 | 成功阈值 |
|---|---|---|
| Early 相对 D 的任务成功率增益 | 越高越好 | 至少 0.05，且 95% CI 下界高于 0 |
| 背景记忆保留率 | 越高越好 | 至少 0.98 |
| 稳定场景任务成功率下降 | 越低越好 | 不超过 0.02 |

统计检验使用轨迹级配对随机化并进行 Holm 校正。

## 资源、复现与结果

- Windows、Python 3.14.0；依赖 Pandas、Matplotlib。
- 单元测试：`python -m unittest discover -s phase3/tests -v`。
- 完整运行：依次执行 Phase 1、Phase 2、Phase 3 脚本。
- Early 相对 D 的任务成功率增益：`0.020`，95% CI `[0.009, 0.032]`。
- 原始配对随机化 p=`0.00065`，Holm p=`0.00195`。
- 背景保留率 `1.000`；稳定场景成功率下降 `0.000`。
- 主要增益门槛未满足，结论为停止或修订当前实现。
